# Fast Lane Tech Service Website

Responsive black-and-gold business website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — site content and structure
- `styles.css` — responsive design and visual styles
- `script.js` — mobile navigation, copyright year, and contact form behavior

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Contact form note
The form validates the required fields and then opens the visitor's default email application with an inquiry addressed to `domoniqueward.dev@gmail.com`. The visitor still needs to press Send. To collect messages without relying on the visitor's email app, connect a form service or backend before launch.

## Publish with GitHub
The repository is `https://github.com/walkdowngaming205-hub/Fast-Lane-Website`. Download the ZIP, extract it, and upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository's `main` branch. Then use the repository's Settings → Pages to enable GitHub Pages from `main` and `/ (root)` if you want a free static site URL.

Before public launch, confirm business details, service descriptions, and any claims about location or turnaround times.
